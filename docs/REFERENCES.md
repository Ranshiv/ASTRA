# References

Every research paper, data archive, and software library ASTRA's engine and
UI draw on, collected in one place. This document is generated by reading
the codebase, not the other way around — see the **Source** column, which
names the exact file the citation lives in.

## How to cite ASTRA itself

See `CITATION.cff` at the repository root. It is currently a stub
(`repository-code`/`license` are placeholders) — treat it as a starting
point, not a finished citation record.

## Link convention

Never invented: every link below resolves one of four ways, in this
priority order, and each entry says which applies.

1. **arXiv** — the paper's arXiv ID appears in the code; linked to
   `arxiv.org/abs/<id>` verbatim.
2. **DOI** — a DOI appears in the code; linked to `doi.org/<doi>` verbatim.
3. **Archive/service URL** — the connector's own endpoint, taken verbatim
   from `research/sources/source_registry.yaml` or the connector's source
   constant.
4. **ADS search** — for a paper cited only as "Author et al. YEAR, Journal"
   in a docstring, with no arXiv ID or DOI in the code. The link is a
   pre-filled [NASA ADS](https://ui.adsabs.harvard.edu/) search for that
   citation string, not a specific bibcode I looked up and asserted —
   verify the exact record before citing it elsewhere.

### Verification status — read this before citing "ASTRA uses X"

Per `research/sources/connector_status.yaml`:

- **`live-verified`** (exercised against the real service, cassette recorded): **ZTF, Gaia** only.
- **`metadata-only`** (returns identity/position rows; light-curve fetch is a documented no-op): Hubble, JWST, Chandra, eROSITA, GALEX, Herschel, Pan-STARRS, SDSS, 2MASS, WISE, XMM, Swift.
- **`mock-only`** (tested only against hand-written mocks, never a real response): TESS, Kepler, ALeRCE, DES, DESI, OGLE, VLASS, Gaia epoch (offline fixture).
- **`dormant`**: Rubin/LSST TAP (credential-gated).

Separately, in `source_registry.yaml` itself, most entries are `status:
registered` (locator recorded) rather than `acquired` (a sealed dataset
manifest with checksum exists) — see `docs/DATA_SOURCES.md` for what those
values mean. Listing a source here documents that ASTRA's code *can* query
it, not that this checkout has *acquired* data from it.
