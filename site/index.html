The premise

One survey calling an object odd is a claim. Two instruments — different detectors, cadences, systematics — agreeing is evidence.

The most common cause of a single-survey anomaly is the survey itself. ASTRA exists to tell the difference.

Schematic of the corroboration logic — not a screenshot of application output.

How it works

Five stages, one ranked list

From raw acquisition to a ranked, explained shortlist of what to look at next.

01

Acquire

Pull observations from independent surveys for a target field or campaign.

02

Extract features

Light curves, astrometry and photometry reduced to comparable feature sets.

03

Detect

Per-survey anomaly detectors score candidates within their own batch.

04

Cross-match & adjudicate

Independent surveys corroborate a signal — or reveal it as an artifact.

05

Rank & explain

A ranked shortlist, each entry with the evidence behind its score.

What it does

Four jobs, in order

Cross-survey corroboration

Matches candidates across independent surveys so a signal has to survive more than one instrument's quirks to count.

Artifact adjudication

Weighs whether an anomaly is astrophysical or a detector, blending, or pipeline artifact before it reaches a ranked list.

Explained flags

Every flagged object comes with the evidence and reasoning behind the score, not just a number.

Ranked follow-up

Surfaces what a researcher should look at next, out of thousands of candidates from a run.

What it is not — and what's next

The honest part

These aren't disclaimers — they change how output should be read.

  • Scores are per-run, not absolute. Detector scores are min-max normalised within a batch; rankings from different runs aren't directly comparable.
  • TESS doesn't resolve individual stars. 21-arcsec pixels mean a TESS match corroborates a neighbourhood, not an object.
  • Composite scores renormalise over available evidence. A score of 0.70 from 75% of the weight isn't the same quantity as 0.70 from all of it — weight_used is reported alongside every score.
  • Injection recovery measures what was injected, not sensitivity to phenomena nobody thought to test for.
  • Almost all evidence is still synthetic-labelled, and the one real result got smaller as it got more honest. A first real TESS artifact-rejection run scored 0.99 mean AUPRC — on just 2 camera groups. Expanded to real diversity (3 CCDs, 4 nights), the honest number fell to 0.64–0.80 depending on grouping, and a domain-adaptation attempt scored worse than doing nothing at all — reported anyway.
BLOCKEDGaia epoch photometry — only the DR3 static table today; DR4's full time-series is the eventual fix, expected December 2026.
BLOCKEDLive-contract validation — Chandra CSC, Swift, XMM, DES, Hubble, JWST and ALeRCE haven't been confirmed against a real response yet; each degrades to zero sources rather than crashing on a mismatch.
SCOPEDDeep-model packaging — deep.train and deep.sweep are excluded from the installer to keep it under 3.5 GB; they run from a development checkout.

Full status — every known gap, what's blocked on what, and what was deliberately left out — is tracked in docs/LIMITATIONS.md.

Build from source

For deep-model work and development

The installer excludes PyTorch and CuPy to stay small. Deep-model training (deep.train, deep.sweep) and GPU acceleration need a development checkout. 

# Windows 11, Node.js LTS, Rust, Python 3.12, VS Build Tools
npm install
uv pip install -e engine          # add [gpu] for PyTorch and CuPy
npm run app                       # Tauri dev: Vite + the Rust shell
