References

What ASTRA is built on

Every research paper, data archive, and software library the engine and UI draw on, collected from the codebase itself — each entry names the file it's cited in. See docs/REFERENCES.md in the repository for the same list in Markdown.

  • Link convention. An arXiv ID or DOI in the code links straight to arxiv.org/doi.org. An archive link is the connector's own endpoint. A paper cited only as "Author et al. Year, Journal" with no arXiv ID or DOI in the code links to a pre-filled NASA ADS search — not a specific record I looked up and asserted.
  • Verification status varies by source. Per research/sources/connector_status.yaml, only ZTF and Gaia are exercised against a real response this session (live-verified). Many survey connectors are metadata-only (identity/position rows; light-curve fetch is a documented no-op) or mock-only (tested only against hand-written mocks). Rubin/LSST TAP is credential-gated and dormant. Listing a source below documents that ASTRA's code can query it — not that this build has acquired data from it.
